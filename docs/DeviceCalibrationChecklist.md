# Device Calibration Checklist

## 1. Purpose

用于完成 OffsetDraw Roadmap 中的真机手感确认。这个清单记录要观察什么，不替代用户在真机上实际绘制。

## 2. Setup

- 使用真机。
- 打开任意作品。
- 展开 More。
- 开启 Calib. grid。
- 从 Balanced 预设开始。
- 连续画 5 分钟，不中途改多个参数。

## 3. Checks

### Long Press

- 观察：长按是否打断第一笔。
- 记录：如果慢，打开 Issues 中的 Long press。
- 调整：关闭 Hold，或切到 Slow 预设对照。

### Stabilizer

- 观察：线是否更稳，笔尖是否拖得太重。
- 记录：如果滞后明显，打开 Issues 中的 Stabilizer。
- 调整：降低 Stabilizer。

### Movement

- 观察：手指移动和笔尖移动比例是否可控。
- 记录：如果比例不自然，打开 Issues 中的 Movement。
- 调整：移动 Movement。

### Smoothing

- 观察：慢速线条是否顺，是否有明显延迟。
- 记录：如果延迟明显，打开 Issues 中的 Smoothing。
- 调整：降低 Smoothing。

### Guide

- 观察：蓝色引导线是帮助理解，还是干扰画面。
- 记录：如果干扰，打开 Issues 中的 Guide。
- 调整：关闭 Guide。

### Cursor

- 观察：静止笔尖是否能让人知道下一笔从哪里开始。
- 记录：如果不清晰，打开 Issues 中的 Cursor。

## 4. Completion

完成校准后：

- 在 Calibrate 中写一句最终手感备注。
- 保留最终参数。
- 回到首页确认缩略图更新。
