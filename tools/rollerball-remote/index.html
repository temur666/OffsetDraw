笔尖与墨水

满压力、静止时的直径。圆形笔尖不旋转。

模拟用力大小；触控笔使用设备提供的压感。

到达这个速度时，直径为当前压力基础的 65%。

越高，高速时越接近下限；最低保留 30% 直径。

越小变化越快；越大过渡越柔和。

设为 0 关闭。收笔越慢、停留越久，墨点越明显。
